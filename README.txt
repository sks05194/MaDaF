MaDaF 0.35.0

MaDaF는 Windows 바탕화면에 Markdown 메모를 배치하는 포터블 프로그램입니다.
이 프로그램은 AI 코딩 도구를 활용해 개발했습니다.
MaDaF는 아직 기능과 안정성을 개선 중인 미완성 프로그램입니다. 계획된 모든 기능과 실제 Windows 환경 검증이 끝난 상태가 아니며, 일부 기능이 미흡하거나 예상하지 못한 오류가 남아 있을 수 있습니다.
중요한 Markdown 파일과 설정은 Portable\Data 외부에도 별도 사본으로 보관하십시오.

실행 방법
1. Windows 10·11 x64용 Portable 폴더 전체를 복사하거나 압축을 풉니다. 실행 파일만 따로 복사하지 마십시오.
2. Portable\MaDaF.exe를 실행합니다.

추가 설치 없이 실행
- 0.27.5부터 실행에 필요한 .NET·WPF 런타임을 Portable 폴더에 함께 포함합니다.
- 지원하는 PC에서는 .NET SDK·Desktop Runtime을 별도로 다운로드하거나 설치할 필요가 없습니다.
- Portable 안의 DLL과 하위 폴더도 프로그램 실행에 필요하므로 파일 구성을 유지하십시오.
- 런타임을 포함하므로 이전 배포본보다 용량이 커집니다.

사용자 데이터
- 메모와 설정은 Portable\Data에 저장됩니다.
- 로그는 Portable\Logs에 저장됩니다.
- 새 버전을 적용할 때 Data와 Logs를 삭제하거나 덮어쓰지 마십시오.
- Data\memo-files.json은 내부 메모 ID와 변경한 실제 파일명의 연결·중단 복구 정보를 보관합니다. 다른 PC로 옮기거나 백업할 때 Memos만 따로 복사하지 말고 Data 폴더 전체를 보존하십시오.
- v0.32.0부터 업데이트 확인으로 프로그램 파일만 갱신할 수 있습니다. v0.34.0부터 설정 → 일반 → 업데이트 확인을 사용합니다. Data·Logs는 교체하지 않습니다.
- 업데이트 기능이 없는 구버전에서 처음 옮길 때에는 앱을 정상 종료하고 Data 전체를 별도 보관한 뒤 새 Portable의 같은 위치로 복사합니다. 메모 확인 전 기존 프로그램 폴더를 삭제하지 마십시오.

휴지통 선택 삭제·렌더링 기반 (0.35.0)
- 휴지통 왼쪽 체크로 대상을 고르고 선택 삭제 (N)를 누릅니다. 행 클릭은 미리보기·개별 복원 대상이며 체크와 별개입니다. 전체 선택은 현재 검색 결과에만 적용하고 검색 조건을 바꾸면 체크를 해제합니다.
- 확인창의 대상만 영구 삭제하며 일부 실패는 이유와 보이는 항목의 체크를 남깁니다. 새 항목은 자동 선택하지 않고 복원 중인 항목은 삭제하지 않습니다. 휴지통 전체 비우기는 검색·체크와 관계없이 적용하는 별도 기능입니다.
- 편집 중 링크는 밑줄로 표시하고 목적지까지 직접 수정합니다. 주소를 클릭해 여는 동작은 미리보기에서 사용합니다. 여러 백틱·이스케이프·복합 강조, ***/___ 구분선과 들여쓴 코드 패널·인용 표시를 보완했습니다.
- 표의 열 맞춤·이스케이프 파이프·빈 셀과 원문 위치를 읽고 미리보기·HTML/RTF 복사에 맞춤을 반영합니다. 셀 수가 다른 표는 내용을 버리지 않고 원문으로 표시합니다. 표는 현재 원문으로 편집하며 표 틀에서 셀을 직접 수정하는 기능은 다음 버전 작업입니다.
- 안정성 245개·별도 App 7개·패키지 21개와 합성 화면 8개를 확인했습니다. 기존 입력 회귀와 서식 선택 경계 3,980가지를 검증했습니다. 교체·재실행 전후 Data 66개 파일·13,524바이트와 메모 8개를 보존했습니다.
- 전체 Markdown 문법, 여러 줄 인라인 코드·경계 공백 정규화, 실제 물리 단축키·Windows IME·다중 모니터/DPI·화면 읽기 확인은 완료 상태가 아닙니다. 기존 단축키 이름 보고와 부분 복원된 항목의 정리 제한은 남아 있습니다.

이전 버전 변경 이력 (현재 동작은 위 0.35.0 안내를 우선합니다)

메모 관리·휴지통 (0.34.0)
- 설정 → 메모 → 휴지통에서 삭제한 메모를 검색하고 원문을 미리 보거나 복원·영구 삭제할 수 있습니다. 휴지통 비우기는 확인한 항목만 처리하며 확인 후 새로 들어온 메모는 남깁니다. 영구 삭제는 되돌릴 수 없습니다.
- 새 삭제는 실제 파일명·모양·잠금·접힘을 보관합니다. 복원 후 표시를 체크하면 설정 창이 있는 화면 안에 표시하며 해제하면 숨김으로 복원합니다. 같은 이름·ID의 메모가 있으면 기존 메모를 덮어쓰지 않습니다.
- 원문과 이력·설정·배치 저장이 끝난 뒤 보관 원본을 정리합니다. 실패·중단된 복원은 원본을 남겨 재개하며 복원 중에는 종료·업데이트를 보류합니다. 보관 자료는 Data\Backups\Deleted에 있고 기본 30일 뒤 앱 시작 시 정리합니다.
- 예전 보관 메모는 이름 정보가 없어 본문으로 확인하고 복원한 메모라는 새 이름으로 복원합니다. 없어진 원래 이름·모양이나 이미 정리된 원문까지 복구하지는 못합니다. 손상 정보·알 수 없는 이력은 보존을 위해 정리가 중단될 수 있습니다.
- 부분 복원 뒤 복원된 메모를 편집하면 두 내용을 보호하기 위해 원본 정리를 중단합니다. 이 경우 활성 메모와 보관 원본은 남지만 앱 안에서 미완료 항목을 병합·정리하는 기능은 아직 없습니다. 필요한 내용을 별도로 보관하고 Data 파일을 임의로 지우지 마십시오.
- 설정 메뉴는 메모·모양·편집·일반·도움말입니다. 현재 버전·업데이트와 앞으로 보기 방식은 일반에서 확인합니다. 도움말의 기존 주제 구성은 유지했습니다.
- 전체·개별 모양에서 사각형 색상 견본을 눌러 색을 선택합니다. HEX 직접 입력·상속·취소 정책은 유지합니다. 저장됨은 2초 뒤 0.4초 동안 글자만 흐려지며 Windows 애니메이션 비활성 설정에서는 바로 숨깁니다.
- 삭제 확인은 내부 ID 대신 실제 파일명을 표시합니다. 물리 Ctrl+Alt+N의 이름 차이 보고는 재현 미확정이며 진입 경로 진단을 추가했습니다.
- 안정성 225개·별도 App 7개·패키지 21개 검사와 화면 11개를 확인했습니다. 교체·재실행 전후 Data 108개 파일·30,113바이트와 기존 메모 8개를 보존했습니다. 실제 단축키·Windows IME·다중 모니터/DPI·화면 읽기의 확인 상태는 별도로 남아 있습니다.

메모 관리·설정 UI/UX (0.33.0)
- 새 메모는 이름을 묻지 않고 새 메모.md, 새 메모 (2).md처럼 고유한 이름과 빈 본문으로 만듭니다. 이름은 나중에 목록의 이름 변경 또는 접힌 제목의 더블클릭으로 바꿉니다. 기존 파일과 내용은 바꾸지 않습니다.
- 메모 목록의 중복 파일명 행과 큰 여백을 줄였습니다. 제목 옆에서 이름 변경·잠금·표시/숨김을 조작하며 화면 이동에서는 대상 화면의 장치명·주 화면·해상도·배율·위치를 확인하고 직접 고릅니다.
- 화면이 한 개이면 화면 이동을 비활성화하고 이유를 안내합니다. 모니터 조회 실패는 별도로 안내하며 잠금을 해제한 메모의 위치 초기화는 계속 사용할 수 있습니다. 숨긴 메모는 화면 이동 뒤에도 숨김을 유지합니다.
- 전체·개별 모양 설정의 항목과 미리보기를 통일했습니다. 글꼴 크기 10~32, 배경 불투명도 20~100%를 숫자로 입력할 수 있습니다. 범위 안의 소수를 허용하며 슬라이더는 각각 0.5와 1씩 조절합니다. 색상은 견본·HEX·색상 선택으로 확인합니다.
- 적용 전 변경은 초안입니다. 잘못된 값은 해당 행에서 안내하고 저장하지 않습니다. 상속을 끄고 켜 비교해도 작성 중인 개별 값은 유지됩니다. 창을 닫을 때 미적용 변경의 적용·버리기·계속 편집을 선택하며 이미 적용한 값은 버리기로 되돌리지 않습니다.
- 적용하지 않은 설정이 있으면 종료·업데이트를 보류합니다. 먼저 설정 창에서 적용하거나 변경을 버리고 닫은 뒤 다시 실행하십시오.
- 도움말은 주제 목록에서 한 개씩 읽습니다. 메모 하단의 저장됨은 2초 뒤 사라집니다. 저장 중과 저장 실패는 유지하며 실패는 최신 내용을 정상 저장한 뒤 해제합니다.
- 전체 안정성 209개·별도 App 통합·패키지 21개 검사와 기본/최소 화면을 확인했습니다. 정상 종료 후·프로그램 교체 직후·재시작 후 Data 전체 103개 파일을 보존했고 기존 메모 8개를 유지했습니다. 실제 단일/다중 모니터·DPI·화면 읽기·Windows IME와 회사 PC 확인은 별도로 남아 있습니다.

데이터 보존 업데이트 (0.32.0)
- 설정 → 메모 → 업데이트 확인에서 새 버전을 확인하고 설치하고 다시 시작을 누릅니다. 설정 창에서 아직 적용하지 않은 변경은 먼저 적용하십시오.
- 기존 공개 Git 배포 저장소의 프로그램을 내려받아 파일 크기·SHA-256·포함 런타임을 확인한 뒤 메모와 배치를 저장하고 종료합니다. 저장 실패나 준비 취소 시 현재 앱을 유지합니다.
- 정상 종료를 확인한 별도 MaDaF 실행 파일이 프로그램 파일만 교체하며 실패 시 이전 프로그램을 복구합니다. Git·.NET SDK·Desktop Runtime·PowerShell 실행 허용은 별도로 필요하지 않습니다.
- 자동 확인·자동 설치·로그인·토큰 저장은 하지 않습니다. 이미 사라진 내용을 복구하는 기능은 아닙니다. 결과·복구 사본은 해당 임시 작업 폴더에 보관하며 자동 정리는 아직 없습니다.
- 전체 안정성 197개·별도 App 검사·런타임 포함 apphost를 확인했습니다. 격리 복사본에서 실제 업데이트 버튼을 통한 파일 교체·재시작과 메모·설정·백업 보존을 확인했습니다. 회사 PC 확인은 별도로 남아 있습니다. 기존 클립보드·DPI·숨김 표시 제한도 유지합니다.

복사 서식 전달 보완 (0.31.3)
- 즉시 편집·미리보기에서 복사하면 Markdown 원문과 함께 HTML·RTF 서식도 전달합니다. 제목·굵기·기울임·취소선·목록·체크 상태·코드·인용·구분선·표·웹 링크를 지원 범위 안에서 내보냅니다.
- 일반 텍스트를 받는 프로그램에는 선택한 Markdown 기호와 줄바꿈이 그대로 전달됩니다. 서식을 받는 프로그램에는 검정 글자·흰 바탕의 서식을 제공합니다. 전체 선택과 부분 선택을 구분하며 잠긴 미리보기에서도 복사할 수 있습니다.
- 기본 WPF RichTextBox에서 제목·굵기·글머리·체크 상태·취소선을 확인했습니다. 한워드 2020은 제목·굵기·체크 상태·취소선을 유지하지만 일반 글머리 표시가 누락되는 제한이 남아 있습니다. Codex·Notion 자체는 아직 확인하지 않았습니다.
- 원문 모드 복사와 MaDaF에 붙여넣기는 기존 일반 텍스트 방식입니다. 외부 서식을 Markdown으로 바꾸는 기능은 포함하지 않았습니다. 큰 문서를 전체 복사하면 잠시 응답이 늦어질 수 있습니다.
- 자동 안정성 검사 183개와 배포 검사 21개를 통과했고 적용 전후 Data 전체 경로·크기·해시가 같음을 확인했습니다.

편집 입력·구분선·복사 수정 (0.31.2)
- Ctrl+A 뒤 Esc를 눌러도 본문은 삭제되지 않고 선택만 해제합니다. 글머리 앞 Space와 대기 입력·한글 조합 뒤 입력의 원문 보존을 보완했습니다.
- 구분선 자체로 커서가 들어가지 않도록 처리하고 글자색을 바꾸면 선도 같은 색으로 표시합니다. 실제 빈 줄은 유지하며 마지막 구분선 뒤 Enter나 본문 입력으로 다음 줄을 만듭니다.
- 미리보기 본문의 더블클릭 위치에서 편집을 시작합니다. 잠금·체크박스·링크의 기존 조작을 유지합니다.
- 새 메모는 파일명 입력 뒤 빈 본문으로 만듭니다. 기존 메모 내용은 바꾸지 않으며 이름 자동 부여는 후속 계획입니다.
- 즉시 편집·미리보기 복사는 Markdown 원문 기호를 보존합니다. 전체 선택은 원문 전체를, 부분 선택은 해당 원문 범위를 복사합니다. 다른 앱에서 자동으로 렌더링하는지는 대상 앱에 따라 확인이 필요합니다.
- 본문만 잘라내면 글머리·번호·체크박스·제목·인용 기호는 유지합니다. 전체 선택 잘라내기는 원문 전체를 지우며 클립보드 기록 실패 시 본문을 지우지 않습니다.
- 자동 안정성 검사 177개와 Data 전체 해시 보존을 확인했습니다. 실제 키보드·Windows IME·Codex·Notion 붙여넣기와 기존 두 모니터·바탕화면 확인은 남아 있습니다.

메모 제목·접기·위치 초기화 (0.31.1 보완)
- 새 메모를 만들 때 제목을 입력합니다. 빈 제목과 이미 사용 중인 제목은 파일 생성 전에 차단하며 입력을 유지합니다. 앞뒤 공백·Unicode 정규화·대소문자 무시 기준으로 숨긴 메모까지 확인합니다.
- 제목은 실제 .md 파일명에서 확장자를 뺀 이름입니다. 새 메모는 입력한 이름으로 파일을 만들고 설정 → 메모 목록의 이름 변경 또는 접힌 제목 더블클릭으로 실제 파일명을 바꿉니다. .md는 자동으로 붙이며 Windows에서 사용할 수 없는 이름은 거부합니다.
- 파일명 변경 전 대기 본문을 저장하며 내부 메모 ID·본문·개별 모양·배치·백업 연결은 유지합니다. 기존 파일을 자동으로 이름 변경하지는 않습니다. 0.31.0의 별도 표시 제목 대신 실제 파일명으로 표시하므로 목록의 첫 내용도 함께 확인하십시오.
- 왼쪽 ∧로 접고 ∨로 펼칩니다. 제목은 접힌 상태에서만 제목줄에 표시합니다. 접으면 잠금·수정 버튼만 사라지고 새 메모·설정·숨김·삭제 버튼은 유지됩니다.
- 접기·숨김·잠금은 독립적입니다. 잠긴 메모도 접고 펼칠 수 있고 잠금 해제는 설정 목록에서 합니다. 접힘 상태와 펼친 크기는 다음 실행에도 복원합니다.
- 설정 → 메모 목록의 위치 초기화는 선택한 메모를 설정 창이 있는 화면 중앙으로 가져옵니다. 잠금 해제 후 사용하며 숨김·본문·모양과 작업 영역에 들어가는 펼친 크기를 유지합니다. 접힌 메모는 제목줄을 중앙에 놓습니다.
- 표시 중인 메모는 위치 초기화에서 표시 창도 다시 만들어 복구를 시도합니다. 같은 편집기와 실행 취소 이력을 유지하며 숨김 메모는 숨김 상태로 위치만 바꿉니다. 숨긴 상태로 시작한 메모가 표시되지 않던 증상은 사용자 재확인이 남아 있습니다.
- 목록은 제목·파일명·첫 내용·상태를 구분하고 여섯 관리 버튼을 같은 폭의 3열·2행으로 정돈했습니다.

웹 하이퍼링크 (0.31.0)
- 미리보기의 일반 HTTP/S 주소와 Markdown 웹 링크를 클릭하면 기본 브라우저로 엽니다. 잠긴 미리보기에서도 사용할 수 있습니다.
- 편집 모드에서는 텍스트를 수정합니다. 코드 내부 URL은 링크로 실행하지 않으며 HTTP/S 이외의 주소는 이 기능으로 열지 않습니다.
- 기본 브라우저 연결과 실제 두 모니터·입력 동작의 사용자 확인은 남아 있습니다. 기존 수동 확인 보류도 유지합니다.

메모 잠금·읽기 모드
- 메모 상단의 자물쇠 버튼을 누르면 해당 메모를 잠그거나 해제합니다.
- 잠긴 메모는 이동·크기 변경·편집과 체크박스 변경을 막습니다. 설정 목록의 다른 모니터 이동도 잠금 해제 후 사용할 수 있습니다.
- 본문 읽기·스크롤·복사·링크는 유지합니다. 메모 영역의 클릭을 아래 바탕화면으로 통과시키지는 않습니다.
- 편집 중 잠그면 입력한 내용을 자동 저장 경로에 반영하고 미리보기로 돌아갑니다.
- 설정 → 메모 목록에서도 잠금·해제를 전환합니다. 숨긴 메모도 잠금 상태를 바꿀 수 있으며 표시·숨김과 잠금은 독립적으로 유지됩니다.
- 잠금 상태는 다음 실행에도 복원합니다. 이전 버전에서 만든 메모와 새 메모는 기본적으로 잠금 해제 상태입니다.
- 숨김·삭제·새 메모·모양 설정은 기존 조작을 유지합니다.

목록 편집
- 즉시 편집에서 글머리·번호·체크박스 목록의 Tab은 현재 항목 또는 선택한 목록 항목을 들여쓰고 Shift+Tab은 내어씁니다.
- 들여쓰기는 파일에 실제 Tab 하나를 추가합니다. 내어쓰기는 앞쪽 들여쓰기에서 Markdown 기준 최대 4칸을 제거합니다. 설정의 Tab 표시 폭과 별개이며 본문과 기존 줄바꿈은 유지합니다.
- 본문 우클릭 → 목록 형식에서 일반 문단·글머리 목록·번호 목록·체크박스 목록으로 전환합니다. 여러 줄을 선택하면 해당 문단들에 함께 적용하며 선택 사이 빈 줄은 유지합니다.
- 같은 형식은 기존 기호·번호·체크 상태를 보존합니다. 새 체크박스는 미완료이며 새 번호는 선택한 들여쓰기 수준별로 1부터 시작하거나 선택 안의 기존 번호를 이어 갑니다. 선택 밖 항목은 바꾸지 않습니다.
- 선택 끝이 다음 줄의 본문 시작이면 그 줄은 제외합니다. 코드·표·HTML·제목·인용·구분선이 섞인 선택은 전체 변경을 보류합니다. 목록과 일반 문단이 섞인 선택의 Tab도 내용을 그대로 둡니다.
- Ctrl+Z로 목록 작업 한 번을 되돌리고 Ctrl+Y 또는 Ctrl+Shift+Z로 다시 실행합니다. 원문·미리보기로 전환한 뒤 다시 편집할 때 선택 범위를 복원합니다.
- 원문 모드에서는 기존 텍스트 편집 방식을 사용합니다. 잠긴 메모는 해제 후 목록을 편집합니다.

메모 선택과 다른 화면의 창 순서
- 0.30.3에서 메모를 처음 누르거나 다시 누를 때의 창 순서 보호를 보완했습니다. 다른 메모의 기존 순서를 유지하면서 선택한 메모를 편집할 수 있도록 처리합니다. 실제 두 모니터에서의 클릭 동작은 사용자 재확인 항목으로 남아 있습니다.
- 0.30.2에서 미리보기·즉시 편집·원문·메뉴 뒤 포커스 복귀에도 다른 메모의 일반 창 기준 순서를 보존하도록 보호 경로를 넓혔습니다.
- 최상위 창을 기준으로 순서를 복원할 때 일반 메모까지 최상위로 바뀌는 오류도 차단했습니다.
- 앞으로 보기가 활성화된 동안에는 모든 표시 메모를 앞으로 보는 기존 동작을 유지합니다. 모드 전환·창 재생성·메모 집합 변경 뒤에는 이전 포커스의 예약 복원을 적용하지 않습니다.

코드 블록 편집
- 즉시 편집에서 줄 시작에 ``` 또는 ~~~를 세 개 이상 입력하면 코드 영역의 배경·테두리·고정폭 글꼴을 바로 적용합니다. 앞에 공백은 최대 3개까지 사용할 수 있습니다.
- 여는 기호 뒤에 csharp 같은 언어 이름을 쓸 수 있습니다. 여는 기호·언어 정보·닫는 기호는 원문 그대로 표시하며 직접 수정·선택·복사할 수 있습니다.
- Enter로 코드 줄을 추가하고 Tab으로 실제 Tab 문자를 넣습니다. 코드 안의 목록·체크박스·굵게·기울임·인라인 코드 기호는 실제 문자로 유지합니다.
- 여는 기호와 같은 종류를 같은 개수 이상으로 한 줄에 입력해 닫습니다. 닫는 기호 뒤에는 공백·Tab만 올 수 있습니다. 그 줄 끝에서 Enter를 누르면 일반 문단으로 돌아갑니다.
- 닫지 않은 블록은 메모 끝까지 코드로 표시합니다. 닫는 기호와 코드 들여쓰기는 직접 입력합니다. 백틱으로 연 블록의 언어 정보에는 백틱을 넣을 수 없습니다.
- 기존 본문·혼합 줄바꿈·선택 밖 원문은 유지합니다. 새 입력·붙여넣기의 줄바꿈은 기존 문서의 첫 줄바꿈 또는 기본 CRLF를 따릅니다.
- Ctrl+Z·Ctrl+Y·Ctrl+Shift+Z와 원문·미리보기 전환을 사용할 수 있습니다. 언어별 색상 구분과 목록·인용 안의 중첩 코드 블록은 현재 지원 범위에 포함되지 않습니다.

Markdown 즉시 편집
- 0.30.3에서 구분선 자체가 불필요하게 한 줄 높이를 차지하던 표시를 줄였습니다. 구분선 앞뒤에 실제로 저장된 빈 줄은 미리보기에도 표시하며 원문의 공백과 줄바꿈은 보존합니다.
- 0.30.1에서 마지막 본문 글자를 Backspace로 지웠을 때 글머리·번호·체크박스·제목·인용 기호까지 사라지는 오류를 수정했습니다. 빈 항목에서 Backspace를 한 번 더 누르거나 Enter를 누르면 기존처럼 해당 형식을 끝냅니다.
- 본문만 선택한 삭제와 Ctrl+A의 전체 문서 삭제를 구분합니다. 빠른 입력·붙여넣기·한글 확정 직후 Backspace도 받은 입력 뒤에서 처리합니다.
- 0.27.4에서 글머리·번호·체크박스 본문 시작에서 왼쪽 방향키를 누르면 이전 줄 끝으로 이동하도록 수정했습니다.
- 삭제·공백 직후 한글 확정이 문서 갱신과 겹쳐 누락될 수 있는 경로를 보완했습니다. 한글 확정 직후 Enter를 눌러도 다음 목록 항목을 이어 씁니다.
- 0.27.3에서 글머리·번호·체크박스 기호 왼쪽으로 커서가 이동하지 않도록 보정하고, 빠른 본문 입력 직후 Enter와 다음 항목 입력 순서를 안정화했습니다.
- 저장 상태를 "저장 중…"으로 줄이고 하단 영역을 한 줄 고정 높이로 바꿔 입력 중 본문이 움직이지 않게 했습니다. Ctrl+Y와 Ctrl+Shift+Z는 모두 다시 실행으로 사용할 수 있습니다.
- 0.27.2에서 화면상 본문이 없는 구분선, 빈 체크리스트와 빈 제목도 전체 선택 뒤 Delete 또는 Backspace로 원문까지 삭제되며 Ctrl+Z·Ctrl+Y로 되돌릴 수 있습니다.
- 0.27.0에서 새 줄의 ---를 원문 그대로 보존하면서 구분선으로 즉시 표시합니다. Enter로 다음 문단을 만들고 Backspace와 실행 취소·다시 실행을 사용할 수 있습니다.
- 0.26.1에서 반복 문자·Tab 주변 수정 위치, 서식 경계를 걸친 교체·줄바꿈, 빠른 체크박스 입력과 갱신 대기 중 커서·선택 보존을 수정했습니다.
- 0.26.0에서 목록 변환 뒤 커서 위치와 Tab 뒤 체크박스·번호 목록 변환을 수정했습니다.
- 메모 본문을 더블클릭하거나 연필 버튼을 누르면 서식을 보면서 편집합니다.
- 줄 앞에서 # 뒤에 공백을 입력하면 제목, - 뒤에 공백과 본문을 입력하면 목록, [] 뒤에 공백은 체크박스, > 뒤에 공백은 인용이 되며 ---는 구분선으로 표시됩니다. 본문 없는 `- ` 줄의 즉시 표시는 현재 동작을 유지합니다.
- **굵게**, *기울임*, ~~취소선~~, `코드`처럼 양쪽 기호를 완성하면 해당 서식으로 표시합니다.
- 목록 끝에서 Enter는 다음 항목을 만듭니다. 빈 항목에서 Enter를 누르면 목록을 끝냅니다.
- </> 버튼은 Markdown 원문 편집, 연필 버튼은 즉시 편집으로 전환합니다. Ctrl+Enter 또는 다른 프로그램으로 이동하면 미리보기로 돌아갑니다.
- Ctrl+Z는 실행 취소, Ctrl+Y 또는 Ctrl+Shift+Z는 다시 실행입니다. 원문 모드에서 내용을 바꾸면 즉시 편집의 이전 실행 취소 이력은 초기화됩니다.
- 내용은 기존 Markdown 파일에 자동 저장합니다. 붙여넣기는 일반 텍스트로 처리합니다.
- 표, HTML 등 복잡한 문법은 즉시 편집에서 원문으로 유지하며 미리보기에서 확인합니다. 전체 Markdown 문법을 시각적으로 편집하는 기능은 아닙니다.

Tab 폭 설정
- 설정 → 편집에서 Tab 폭을 1~8칸으로 조절합니다. 기본값은 4칸입니다.
- 적용을 눌러 저장하며 기본값 4칸 버튼도 적용 후 저장합니다. 적용하지 않고 닫으면 변경을 저장하지 않습니다.
- 즉시 편집과 미리보기에 적용하며 파일의 Tab 문자는 유지합니다. </> 원문 편집의 Tab 표시 폭은 기존 컨트롤 기본값을 따릅니다.
- Tab 뒤 [] + 공백, [ ] + 공백 또는 [x] + 공백을 입력하면 들여쓴 체크박스가 됩니다. Enter로 들여쓰기를 유지한 다음 항목을 만듭니다.

메모 모양과 글꼴 크기
- 트레이의 설정 → 모양에서 전체 메모의 기본 색상, 배경 불투명도와 글꼴 크기(10~32, 기본 14)를 변경합니다.
- 메모 오른쪽 위의 톱니바퀴 또는 설정의 메모 목록 → 메모 설정에서 해당 Markdown 파일의 전체 경로를 확인하고 모양을 개별 설정합니다. 경로는 읽기 전용 정보로 표시하며 선택·복사할 수 있습니다.
- 0.30.3에서 하단의 상시 모드·조작 안내를 정리했습니다. 저장 중·저장됨·저장 실패 상태는 유지하고, 입력 중 본문이 움직이지 않도록 상태 영역 높이는 고정합니다.
- 체크한 항목만 개별 적용하며 나머지는 전체 설정을 따릅니다. 전체 설정을 바꾸어도 개별 지정한 값은 유지됩니다.
- 변경 중에는 미리보기만 바뀝니다. 적용을 눌러 저장하며, 적용 전 취소는 저장하지 않습니다.
- 전체 설정 따르기 → 적용으로 개별 지정을 해제합니다.
- 글꼴 크기는 메모 내용 전체에 적용되며 창 크기와 Markdown 내용은 변경하지 않습니다.

스크롤바
- 0.27.1에서 실제 프로그램 시작 시 공통 스크롤바 테마가 로드되지 않던 오류를 수정했습니다.
- 메모, 즉시 편집, 원문 편집과 설정 화면은 얇고 둥근 공통 스크롤바를 사용합니다.
- 포인터를 올리거나 끌 때 스크롤 손잡이가 선명해지며 기존 휠·트랙 클릭·드래그 방식은 그대로 사용할 수 있습니다.

Markdown 백업과 복구
- MaDaF 실행 중 같은 Markdown 파일을 외부 편집기로 바꾼 뒤 MaDaF에서도 저장하면, 0.27.2부터 외부 변경 내용을 5분 간격과 무관하게 즉시 백업한 다음 MaDaF 내용을 저장합니다. 외부 변경을 화면에 자동 반영하거나 병합하지는 않습니다.
- 복구할 백업은 선택 직후 내용을 확보하므로, 복구 전 대기 저장이 백업 보관 한도를 정리해도 선택한 내용을 복구할 수 있습니다. 현재 내용은 복구 직전에 별도 백업합니다.

종료 시 저장 확인
- 메모나 배치를 저장하지 못하면 트레이 종료와 로컬 업데이트를 보류합니다.
- 메모는 열린 상태로 유지되며 자동 저장을 다시 시도합니다. 파일 잠금과 디스크 공간을 확인한 뒤 종료나 업데이트를 다시 요청하십시오.
- 강제 종료와 전원 차단 시에는 저장을 보장하지 않습니다.

이 저장소에는 사용자별 Data, Logs와 개발용 디버그 심볼이 포함되지 않습니다.
